Il tool del calcolo del rumore tonale di una propeller è contenuto all'interno della cartella noise_computation. 
Sono necessarie analisi BEMT per lo svolgimento del calcolo. Sono presenti due simulazioni già processate.

E' stata implementata una formulazione simil Gutin-Lowson, per simulazioni steady e unsteady loading.

Sono state svolte validazioni del tool contro reference data di un modello a più alta fedeltà e sono stati calcolati spettri e plot di direttività delle sorgenti. 
Viene proposto un confronto con un tool Hanson (trovato su repo online, di J. Goyal).

Il nome degli script .m semanticamente consente di orientarsi nella cartella.
